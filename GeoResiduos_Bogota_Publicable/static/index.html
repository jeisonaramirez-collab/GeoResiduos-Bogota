Proyecto aplicado · Ingeniería de Sistemas

Este prototipo presenta interfaces, flujo de registro, georreferenciación y consulta. Las operaciones administrativas requieren autenticación. No se envían reportes a entidades oficiales.

Componentes previstos

Aplicación conectada al servidor

La plataforma utiliza Flask para conectarse a una base de datos. El servidor principal utiliza Flask, conforme a la tecnología propuesta en el documento maestro., PostgreSQL/PostGIS, validaciones de servidor, almacenamiento seguro de archivos y controles de acceso.
