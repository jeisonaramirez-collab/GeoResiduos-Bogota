# GeoResiduos-Bogota
Prototipo web académico orientado al registro, consulta, gestión y visualización geográfica de puntos críticos de disposición inadecuada de residuos sólidos en Bogotá D. C. El sistema integra formularios de reporte, almacenamiento de información, consulta de registros, visualización cartográfica y funcionalidades administrativas.
